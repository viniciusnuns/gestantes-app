Sempre pedir para o usuário evidenciar o erro (logs, screenshots, dados reais) antes de diagnosticar a causa raiz.

**Why:** O usuário questionou que eu diagnostiquei a causa de um e-mail não enviado (Maria Eduarda, 07/21) sem evidência real — apenas identifiquei vulnerabilidade no código e assumi que foi o problema.

**How to apply:** Quando um bug é reportado, primeiro perguntar "você tem o log de erro / screenshot / dado que comprova isso?" antes de concluir qual foi a causa. Especialmente para erros em produção que podem ter múltiplas causas possíveis.
