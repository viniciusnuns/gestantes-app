## Story

**Como** usuária do Gestar em Movimento navegando na Biblioteca,
**Quero** que o app busque os dados de um exercício específico (incluindo o `youtube_video_id`) de forma eficiente,
**Para que** o vídeo correto seja carregado quando eu entrar na página do exercício.

## Acceptance Criteria

1. Existe um endpoint `GET /api/exercises/[id]` que retorna o exercício pelo ID, incluindo o campo `youtube_video_id` (pode ser `null` para exercícios sem vídeo).
2. O endpoint retorna `404` com mensagem clara quando o exercício não for encontrado.
3. Existe um hook `useExercise(id: string)` em `lib/hooks/useExercise.ts` que faz o fetch de um único exercício pelo ID.
4. O hook retorna `{ exercise, isLoading, error }` — segue o padrão de hooks existentes no projeto.
5. O hook utiliza o endpoint criado no AC1 (não lê diretamente de `lib/data.ts`).
6. A página `app/biblioteca/[id]/page.tsx` pode substituir a leitura direta de `lib/data.ts` pelo hook `useExercise` sem quebrar funcionalidades existentes.
7. TypeScript não gera erros (`npm run typecheck` passa).
8. Lint passa sem novos warnings (`npm run lint`).

**Nota sobre escopo:** A substituição efetiva na página `app/biblioteca/[id]/page.tsx` é opcional nesta story — o AC6 exige apenas que seja tecnicamente possível sem quebrar nada. A integração real acontece na Story 1.3.

**Padrão de API Route (Next.js 14 App Router):**
```typescript
// app/api/exercises/[id]/route.ts
import { NextResponse } from 'next/server'
import { exercises } from '@/lib/data'

export async function GET(
  _request: Request,
  { params }: { params: { id: string } }
) {
  const exercise = exercises.find((ex) => ex.id === params.id)
  if (!exercise) {
    return NextResponse.json(
      { error: 'Exercício não encontrado' },
      { status: 404 }
    )
  }
  return NextResponse.json(exercise, {
    headers: { 'Cache-Control': 'public, max-age=3600' },
  })
}
```

**Padrão do hook (baseado nos hooks existentes do projeto):**
```typescript
// lib/hooks/useExercise.ts
'use client'
import { useState, useEffect } from 'react'
import type { Exercise } from '@/lib/data'

export function useExercise(id: string) {
  const [exercise, setExercise] = useState<Exercise | null>(null)
  const [isLoading, setIsLoading] = useState(true)
  const [error, setError] = useState<string | null>(null)

  useEffect(() => {
    if (!id) return
    setIsLoading(true)
    fetch(`/api/exercises/${id}`)
      .then((res) => {
        if (!res.ok) throw new Error('Exercício não encontrado')
        return res.json()
      })
      .then((data) => setExercise(data))
      .catch((err) => setError(err.message))
      .finally(() => setIsLoading(false))
  }, [id])

  return { exercise, isLoading, error }
}
```

**Nota sobre fonte de dados:** Nesta story, o endpoint lê de `lib/data.ts` (mock). Em uma versão futura, quando a tabela `exercises` for migrada para o Supabase, o endpoint será atualizado para buscar do banco. O contrato da API (`GET /api/exercises/[id]`) permanece o mesmo.

### Decisões de implementação

1. **SWR vs vanilla useState/useEffect**: Optado por vanilla conforme Dev Notes da story — SWR/React Query não estão no `package.json`, instalação de dependências está bloqueada nesta sandbox, e o padrão vanilla casa com `lib/hooks/useActivityInit.ts` (consistência interna).
2. **Retry automático**: O spawn prompt menciona 3 tentativas, mas a story (fonte da verdade — Article III) não exige retries. Sem SWR/React Query, retries custariam código adicional não justificado. Tratamento de erro robusto + ID de erro claro (404 vs 5xx) cobrem os ACs.
3. **`encodeURIComponent(id)`**: Adicionado por segurança, mesmo com IDs internos (`ex-1`). Defesa em profundidade.
4. **Flag `cancelled` no useEffect**: Previne updates de state após unmount do componente — boa prática React.
5. **Cache-Control**: Aplicado `public, max-age=3600, s-maxage=3600` (1h) — exercícios mock mudam raramente; CDN também pode cachear.
6. **500 handler**: Try/catch envolvendo o handler como segurança, mesmo que `find` em array nunca lance — preparação para migração futura ao Supabase.
