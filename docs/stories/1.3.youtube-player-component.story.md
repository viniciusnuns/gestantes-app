## Story

**Como** gestante usando o Gestar em Movimento,
**Quero** assistir ao vídeo do exercício diretamente dentro do app ao entrar na página do exercício,
**Para que** eu possa ver a demonstração correta antes de praticar, sem sair do app.

## Acceptance Criteria

1. Existe o componente `components/video/YouTubePlayer.tsx` que renderiza um iframe do YouTube.
2. O player usa os parâmetros: `modestbranding=1`, `rel=0`, `showinfo=0` — suprimindo sugestões de outros canais e branding excessivo.
3. O player tem aspect ratio 16:9 e é responsivo (largura 100% do container pai).
4. A página `app/biblioteca/[id]/page.tsx` substitui o botão Play placeholder pelo componente `YouTubePlayer` quando o exercício possui `youtube_video_id`.
5. Quando o exercício NÃO possui `youtube_video_id`, a área de vídeo exibe apenas a imagem existente com o botão Play placeholder desabilitado (comportamento atual, sem alteração visual).
6. O componente é carregado de forma lazy — o iframe só é inserido no DOM após a usuária tocar no botão Play (não no page load).
7. O player ocupa a área hero (aspect-ratio 16:10, mesmo container da imagem atual) substituindo a imagem quando ativado.
8. TypeScript não gera erros (`npm run typecheck` passa).
9. Lint passa sem novos warnings (`npm run lint`).

### Interface do Componente YouTubePlayer

```typescript
// components/video/YouTubePlayer.tsx
interface YouTubePlayerProps {
  videoId: string
  className?: string
}
```

**Implementação sugerida (lazy mount pattern):**
```tsx
'use client'
import { useState } from 'react'
import { Play } from 'lucide-react'

export default function YouTubePlayer({ videoId, className }: YouTubePlayerProps) {
  const [isPlaying, setIsPlaying] = useState(false)

  if (!isPlaying) {
    return (
      <div
        className={`relative w-full aspect-video bg-black cursor-pointer ${className}`}
        onClick={() => setIsPlaying(true)}
        role="button"
        aria-label="Reproduzir vídeo"
      >
        {/* Thumbnail via YouTube API */}
        <img
          src={`https://img.youtube.com/vi/${videoId}/hqdefault.jpg`}
          alt="Miniatura do vídeo"
          className="w-full h-full object-cover"
        />
        <div className="absolute inset-0 flex items-center justify-center">
          <span className="w-16 h-16 rounded-full bg-white/90 text-primary-400 flex items-center justify-center shadow-lg">
            <Play size={28} fill="currentColor" className="ml-1" />
          </span>
        </div>
      </div>
    )
  }

  return (
    <div className={`relative w-full aspect-video ${className}`}>
      <iframe
        className="w-full h-full"
        src={`https://www.youtube.com/embed/${videoId}?autoplay=1&modestbranding=1&rel=0&showinfo=0`}
        allow="autoplay; encrypted-media; picture-in-picture"
        allowFullScreen
        title="Vídeo do exercício"
      />
    </div>
  )
}
```

### UX Gestante — Considerações

- **Autoplay ao tocar Play:** a usuária deve ver o vídeo tocar imediatamente após tocar no botão — não deve precisar tocar Play duas vezes (um no nosso botão, outro no iframe do YouTube).
- **Thumbnail:** usar a URL da miniatura do YouTube (`hqdefault.jpg`) em vez da imagem do Unsplash para dar contexto visual do vídeo real.
- **Conexão 3G:** o iframe só carrega quando a usuária toca Play — nunca no page load. Isso é crítico para performance em redes móveis.
- **Gestante no celular:** garantir que o player ocupe a largura completa da tela em mobile, sem barras laterais ou cortes.
