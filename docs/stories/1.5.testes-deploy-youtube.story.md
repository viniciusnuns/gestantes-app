## Story

**Como** equipe do Gestar em Movimento,
**Quero** validar a integração YouTube em condições reais (rede 3G, dispositivos móveis) antes de disponibilizar para todas as usuárias,
**Para que** possamos identificar e corrigir problemas antes do lançamento completo e aprender com os dados de engajamento de um grupo menor.

## Acceptance Criteria

1. Um smoke test manual documentado é executado cobrindo o fluxo completo: login → Biblioteca → selecionar exercício com vídeo → Play → vídeo toca → "Completei a prática" → ponto computado.
2. O smoke test é realizado simulando conexão 3G (throttle via Chrome DevTools: "Slow 3G" preset) e o vídeo inicia em menos de 10 segundos após toque no Play.
3. O smoke test é realizado em pelo menos 2 viewports: mobile 375px (iPhone SE) e tablet 768px.
4. O resultado do smoke test é registrado em `docs/qa/smoke-test-youtube-2026-05-25.md` com screenshots ou descrição de cada passo.
5. O deploy do soft launch é realizado pelo @devops — NÃO é responsabilidade desta story configurar infra, apenas documentar o checklist de validação pós-deploy.
6. O checklist pós-deploy inclui: verificar que `/biblioteca/ex-1` carrega em produção com vídeo, verificar que registro na tabela `video_progress` ocorre em produção, verificar que exercícios sem vídeo (ex-6) permanecem funcionais.
7. Qualquer bug encontrado durante os testes é documentado em `docs/qa/smoke-test-youtube-2026-05-25.md` com passos para reprodução — não precisa ser corrigido dentro desta story (pode abrir novas stories).
8. Lint e typecheck passam na branch de deploy.

### Escopo desta Story

Esta story é de **validação e documentação**, não de implementação de funcionalidades. O @dev executa os testes e documenta. O @devops realiza o deploy efetivo em produção.

**NÃO está no escopo:**
- Configurar ambiente de produção
- Configurar Vercel, Supabase produção, DNS
- Criar feature flags ou sistema de rollout percentual
- Corrigir bugs encontrados (esses viram novas stories)

**O "soft launch 20% usuárias" mencionado no brief é responsabilidade do @devops** — esta story documenta o que validar, não como implementar o rollout.

### Configurações de Throttle (Chrome DevTools)

- **Slow 3G:** 400 Kbps download, 400 Kbps upload, 400ms latência
- Acesso: F12 → Network tab → dropdown "No throttling" → "Slow 3G"
- Tip: desativar throttle antes de recarregar a página de testes para não afetar login
